# Circular Progress Bar 🔄

A modern and animated Circular Progress Bar built using HTML, CSS, and JavaScript.  
This project visually represents progress percentages with smooth animations and responsive design.

## 🚀 Features
- Animated Circular Progress
- Dynamic Percentage Display
- Responsive Design
- Clean and Modern UI
- Smooth CSS Animations
- Easy Customization

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📸 Project Preview
An interactive circular progress indicator designed to display progress in a visually appealing way.
